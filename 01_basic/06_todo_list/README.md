# Todo App

A simple, interactive task management application built with Python and Streamlit.


## Features

* Add new tasks to your list
* Mark tasks as completed
* Delete tasks when they are no longer needed
* Clean, responsive, and easy-to-use interface

## Technologies

* Python
* Streamlit

## Local Setup

This project runs locally on your machine
